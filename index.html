_project_details: CryptLock

CryptLock is a Python-based real-time ransomware detection and response system built entirely for the terminal — no GUI, no cloud dependency, just pure defensive security engineering. It monitors a target directory and automatically detects, alerts, and responds to ransomware-like behaviour before damage occurs.

Key Features & Capabilities:
  • Shannon Entropy Analysis: Reads file bytes and measures randomness to detect encryption in real-time (encrypted files score 7–8/8 bits).
  • Sliding-Window Behaviour Engine: Detects mass file renames, bulk modifications, rapid deletions, and burst activity spikes within a 10-second window.
  • Weighted Risk Scoring (0–100): Combines multiple signals into a live risk tier — NORMAL → SUSPICIOUS → RANSOMWARE.
  • Automated Incident Response: Kills suspicious processes, quarantines files, and logs full forensic reports on confirmed threats.
  • Safe Ransomware Simulator: Built-in controlled simulation to stress-test the detection engine without real malware.
  • File Backup & Recovery: Auto-backup system with one-command restore to recover files after an attack.
  • Flask Monitoring Dashboard: Live threat visualisation with event logs and risk gauge accessible via browser.
